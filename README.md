# Personal Autobiography Web Page

A semantic HTML5 and CSS3 personal autobiography website project completed as a laboratory activity for Saint Michael College of Caraga.

## 🚀 Live Demo / Features
- **Semantic HTML5 Markup**: Implemented `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<figure>`, and `<footer>`.
- **Navigation Bar**: Horizontal navigation menu with smooth internal scrolling and hover animations.
- **Structured Sections**:
  - **About Myself**: Profile picture, personal details card, and two-column life stages (Childhood, Teenage Life, Adulthood).
  - **My Hobbies**: Organized inside and outside hobbies using styled unordered lists.
  - **My Favorites**: Highlights favorite artist, food, and place accompanied by responsive images and descriptions.
- **Modern Responsive CSS**: Clean typography, system font stack, flexbox, and CSS grid layout.
